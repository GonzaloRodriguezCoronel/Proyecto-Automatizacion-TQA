AYUDA

Cómo utilizar TQA Center

El proceso completo de automatización y reporte desde una sola aplicación.

1. Seleccionar

Elige aplicación, motor y casos. Para Selenium IDE, la demo integrada funciona sin cargar archivos.

2. Ejecutar

Estándar prueba API y rendimiento, Selenium automatiza interfaz y Robot genera scripts.

3. Observar

Con Selenium en modo integrado, las capturas del navegador se actualizan tras cada paso dentro del panel. No es un video continuo.

4. Documentar

PDF + HTML + evidencias + historial. El correo se envía si SMTP está configurado.

5. Selenium IDE

Genera casos a partir de cualquier pantalla HTML autorizada y suites generales de navegación. Los proyectos .side de Selenium IDE se pueden importar y ejecutar con WebDriver. Las métricas de rendimiento, accesibilidad y responsividad se ejecutan con comprobaciones propias de TQA; no son comandos nativos .side. Carga/estrés requiere otro motor.

6. Entorno seguro

Utiliza cuentas de prueba y aplicaciones autorizadas. Los resultados PASS/FAIL siempre proceden de las comprobaciones reales.
